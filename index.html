Why did we create this website?

We created this website to help volunteers remove invasive species.

How does this website work?

We send a robot into the wild to search for invasive plants. When it finds one, it returns and tells us exactly where the plant is located. We then post its location on the website. Volunteers—or anyone who wants to help—can visit the site and remove the invasive plant. The information section below explains how to remove each plant safely and lists the materials you'll need. You can use it even if you're new to invasive species and want to help the environment.
